# tacuae

The Total Automation Co. LLC (TAC UAE) website and platform, deployed with Docker and GitHub Actions.

| Folder | What it is | Port on server |
|---|---|---|
| `tac-site-c` | Website, configurators, quotations, dashboards and admin (`/admin`) | 8082 |

Vite + React + TypeScript + Tailwind, served by an Express API with MongoDB.
See **[DEPLOY.md](DEPLOY.md)** for the CI/CD pipeline and server setup.
